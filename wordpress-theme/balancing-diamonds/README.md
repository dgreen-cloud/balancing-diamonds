# Balancing Diamonds WordPress Theme

A custom, lightweight WordPress theme built from the **Balancing Diamonds Unified Master Blueprint**.

## What the theme does

- Presents the site as a parchment-lit private library and editorial maison.
- Uses standard WordPress posts for essays, so Ulysses can publish directly into the Journal.
- Organizes essays through the Four Rooms as categories: Self, House, Work, and World.
- Organizes the Diamond Axis through tags: Worth, Voice, Truth, Balance, Dignity, and Authorship.
- Includes a one-click Maison Setup screen under **Appearance > Maison Setup**.
- Creates the eight core pages and five canonical launch essays as drafts.
- Includes Parchment Maison and Night Library modes.
- Uses no page builder and no required plugin.
- Supports the WordPress block editor, featured images, excerpts, menus, custom logos, and newsletter shortcodes.

## Install on Spaceship WordPress

1. Upload `balancing-diamonds.zip` in **WordPress Admin > Appearance > Themes > Add New Theme > Upload Theme**.
2. Install and activate **Balancing Diamonds**.
3. Open **Appearance > Maison Setup** and select **Build the Maison**.
4. Open **Appearance > Customize > Maison Settings** and add:
   - founder name;
   - newsletter URL or newsletter form shortcode;
   - collaboration email;
   - editions or shop URL.
5. Review the generated pages and the five draft essays before publishing.
6. Set a logo and site icon under **Appearance > Customize > Site Identity**, if desired.

The starter installer never replaces existing pages or posts. It creates only missing items.

## Recommended WordPress settings

- **Settings > General**: Site Title `Balancing Diamonds`.
- **Settings > Tagline**: `Move from performance to self-authorship.`
- **Settings > Permalinks**: `Post name`.
- Keep essay comments off unless there is a deliberate moderation strategy.
- Use excerpts as editorial decks and featured images only when they deepen the work.

## Optional plugins

- A newsletter platform plugin such as MailPoet, or a hosted signup URL from Kit, Mailchimp, or Buttondown.
- An SEO plugin for advanced metadata and sitemaps.
- A caching plugin only if Spaceship does not already provide page caching.

Avoid stacking page builders and visual-effect plugins. The theme is intentionally complete and lightweight.
