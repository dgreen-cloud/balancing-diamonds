# Publishing Balancing Diamonds Essays from Ulysses

The theme uses standard WordPress posts, so Ulysses can publish essays without custom code or a page builder.

## One-time connection

1. In Ulysses on iPhone, iPad, or Mac, open a sheet and choose **Export**.
2. Choose **Publishing**, then **WordPress**.
3. Enter the complete site URL, such as `https://balancingdiamonds.com`.
4. Sign in to the WordPress authorization screen and approve Ulysses.

## Editorial metadata mapping

Before publishing, use Ulysses publishing settings to set:

- **Title**: the essay title.
- **Slug**: a short, permanent URL slug.
- **Status**: Draft for editorial review, then Published when final.
- **Excerpt**: the essay deck shown beneath the title and on Journal cards.
- **Featured image**: optional, sparse, atmospheric, and directly relevant.
- **Category**: one primary Four Rooms category: Self, House, Work, or World.
- **Tags**: one or more Diamond Axis themes: Worth, Voice, Truth, Balance, Dignity, or Authorship.

Ulysses keywords can map to WordPress tags or categories when the same terms already exist in WordPress. The Maison Setup creates the official terms first so the names stay consistent.

## Editorial standard

Every essay should make a precise claim, reveal a real pattern, connect inner and outer life, respect the reader's intelligence, and contribute to the permanent archive.

The design creates the room. The writing must carry it.
